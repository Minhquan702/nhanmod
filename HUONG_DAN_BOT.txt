TD MOD TELEGRAM — GARENA GALLERY V3

1. CÀI ĐẶT RAILWAY
- Dùng repository và service riêng cho bản bot này. Upload toàn bộ source trong ZIP, giữ đúng cấu trúc thư mục.
- Start Command: python bot.py. Python 3.12; requirements.txt đã ghim phiên bản.
- Tạo public domain HTTPS cho service BOT.
- Variables bắt buộc:
  BOT_TOKEN: token của bot lấy từ BotFather.
  BOT_PUBLIC_URL: domain HTTPS của service BOT, không thêm /webapp/ vào cuối.
  VUOTLINK_API: API nhiệm vụ.
  BOT_ADMIN_PASSWORD: mặc định 177207 theo yêu cầu; đặt biến này nếu muốn đổi mật khẩu.
  BOT_ADMIN_IDS: Telegram ID admin, nhiều người ngăn bằng dấu phẩy. Mặc định giữ ID admin từ source cũ: 8287067985.
- BOT_PUBLIC_URL phải là domain bot mới, KHÔNG dùng domain web tạo mod hiện tại.
- Bot tự đặt nút menu TD MOD. Mở bot trong chat riêng và bấm /start.
- Chỉ chạy một service polling cho một BOT_TOKEN. Dừng service bot cũ khi thay bot mới để tránh lỗi Conflict. Web hiện tại không cần dừng hoặc sửa.

2. LƯU DỮ LIỆU
- Gắn volume RIÊNG cho service bot, ví dụ /data.
- BOT_STORAGE_DIR=/data/BotJobs. Nếu có RAILWAY_VOLUME_MOUNT_PATH, source tự dùng thư mục BotJobs trong volume đó.
- Không dùng chung volume/thư mục jobs với web.
- Nếu không có volume, lịch sử, ZIP, thông báo và nhạc có thể mất khi redeploy.
- File được giữ mặc định 24 giờ; BOT_FILE_TTL có thể đặt từ 3600 đến 604800 giây.
- Nếu máy chủ restart giữa lúc tạo, lịch sử sẽ báo lỗi cho lượt đó để người dùng tạo lại.

- Lệnh /start, /mod, /webapp, /choosehero, /run, /history, /settings mở ứng dụng; /help hướng dẫn; /admin thống kê nhanh (đúng ID admin).

4. HAI BẢN ĐỘC LẬP
Bot không gọi API web, không cần web online, không dùng dữ liệu/jobs/queue/password/nhạc/thông báo của web. Web gốc không bị chỉnh sửa. Hai service vẫn có thể cùng chịu ảnh hưởng nếu dùng chung tài khoản hosting bị hết tài nguyên hoặc cùng phụ thuộc dịch vụ nhiệm vụ.
